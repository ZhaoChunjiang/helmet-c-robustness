# Helmet-C Robustness

Official implementation and evaluation code for the Helmet-C robustness benchmark.

This repository contains the code, configuration files, fixed data splits, and evaluation scripts used in our experiments.

## Contents

- Degradation generation
- Helmet-C benchmark construction
- Robustness evaluation
- Fixed data splits and random seeds
- Experimental result summaries
